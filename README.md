# AFMG – Aspire Football Management Group

AFMG is a professional club management website featuring player profiles, 
statistics, staff sections, and a modern UI. Built as a clean, performant 
full-stack platform for managing player information and presenting club details.

## 🌐 Live Site
https://afmg.co.uk

## 🧰 Tech Stack
- TypeScript
- Vite
- Neon (PostgreSQL)
- Netlify hosting
- Tailwind CSS

## 🏗 Features
- Player database with stats, bios, and images
- Management team section
- About Us and club overview pages
- Scrollable player list with individual profile pages
- CMS-style editing workflow (in-progress)
- Fully responsive design

## 🗄 Database (Neon)
- PostgreSQL player table (stats, numbers, positions, bio)
- API-driven data retrieval
- Structured for future expansion (fixtures, academy, staff CMS)

## 🚀 Getting Started
npm install  
npm run dev
