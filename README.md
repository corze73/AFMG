# Aspire Football Management Group ⚽

**AFMG** is a responsive website built for Aspire Football Management Group — a football talent development and management organization. The site provides an overview of the management team, player profiles, and contact information, and is built using clean HTML, CSS, and JavaScript.

---

## 🌐 Live Site

🔗 [Visit the AFMG website](https://afmg.co.uk/)

---

## 🧠 Project Purpose

This project was designed as part of my Full Stack Developer journey, showcasing a real-world club website with a clean layout, dynamic sections, and role-based access. It reflects my growing focus on combining frontend development with football industry knowledge.

---

## 💡 Features

- 📌 Fixed header with Aspire logo and smooth navigation links
- 🧑‍💼 Management section with team bios and placeholders
- 📝 Player section with scrollable profiles and editable player data
- 🧾 About Us + Contact page
- 📱 Fully responsive for mobile and desktop
- 🔐 Role-based access (Admin & Player)
- 🌐 Deployed using Netlify

---

## 🗂️ Tech Stack

- **HTML5**
- **CSS3**
- **JavaScript**
- **GitHub + Netlify** (for version control and deployment)
- [Supabase](https://supabase.com/) (private backend for player data)
